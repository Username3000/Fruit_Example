# Как открыть Fruit Example

1. Установите Unreal Engine **5.8**.
2. На [странице проекта](https://github.com/Username3000/Fruit_Example) откройте ветку `main` и выберите **Code → Download ZIP**. Распакуйте весь архив в новую папку. Если работаете через Git, можно клонировать репозиторий.
3. Откройте `Fruit_Example.uproject` в Unreal Editor. Редактор загрузит карту `L_Example`.

Ассеты уже входят в скачанный проект. Git LFS и предварительная установка ассетов не нужны.

Если Unreal сообщает, что `L_Example.umap` «appears to be an asset file», запустите `SETUP_PROJECT.bat` для проверки файлов. Если проверка нашла указатели Git LFS, у вас старый архив. Скачайте [актуальный ZIP ветки main](https://github.com/Username3000/Fruit_Example/archive/refs/heads/main.zip). Если в старой папке есть свои изменения, оставьте её для переноса этих изменений.
