# Fruit Example

Учебный Blueprint-проект на **Unreal Engine 5.8**: аркада с разрезанием
фруктов движением мыши, Niagara-эффектами, предметами и интерфейсом игры.

## Запуск

1. Установить Unreal Engine **5.8**, Git и **Git LFS**.
2. Клонировать репозиторий и загрузить бинарные ассеты:

   ```powershell
   git lfs install
   git clone <URL-репозитория>
   cd Fruit_Example
   git lfs pull
   ```

3. Открыть `Fruit_Example.uproject` и дождаться подготовки шейдеров.
4. Запустить **Play**. Стартовая карта — `/Game/Root/Maps/L_Example`.
5. Зажать левую кнопку мыши и провести курсором через фрукт.

Папка после клонирования обычно совпадает с именем репозитория; если оно другое,
использовать это имя в команде `cd`. Проект работает на Blueprint; сборка C++
для открытия не требуется. Движок в репозиторий не входит.

## Содержимое

| Путь | Назначение |
|---|---|
| `Content/Root/Maps` | Игровая карта |
| `Content/Root/Blueprints` | Игровая логика, фрукты, предметы, контроллер и UI |
| `Content/Root/Assets` | Модели, материалы, текстуры и Niagara-системы |
| `Config` | Общие настройки Unreal |
| `SourceAssets` | Исходные модели и изображения, архивы наборов и сведения об авторах |
| `Tools` | Скрипты импорта, настройки и проверки ассетов через Unreal MCP |

В `Content` уже сохранены игровые ассеты. Для обычного запуска повторять импорт
или выполнять скрипты настройки не нужно. `Saved`, `Intermediate`,
`DerivedDataCache`, виртуальные окружения Python и настройки рабочего компьютера
исключены из Git и создаются локально.

## Работа с ассетами

Файлы Unreal, исходные бинарные модели, изображения и архивы хранятся через
**Git LFS**; правила заданы в `.gitattributes`. При клонировании нужен Git LFS,
чтобы вместо файлов-указателей получить сами ассеты.

Документация отдельных подсистем:

Скрипты в `Tools` включают операции изменения и пересоздания ассетов; перед
запуском следует прочитать документацию соответствующей подсистемы.

## Unreal MCP (необязательно)

Для автоматизации редактора используется локальный Python MCP-сервер.
Он не нужен для игры. Установка и команды описаны в
[Tools/UnrealMCP/README.md](Tools/UnrealMCP/README.md).

Личная `.codex/config.toml` исключена из Git. Для нового компьютера скопировать
[пример](.codex/config.example.toml) в `.codex/config.toml` и заменить пути
на локальные. Редактор должен быть открыт с этим проектом. Удалённое выполнение
Python настроено на loopback-интерфейс.

## Публикация на GitHub

Репозиторий использует ветку `main`. Из корня проекта, при установленном
и авторизованном GitHub CLI:

```powershell
gh repo create Fruit_Example --public --source=. --remote=origin --push
```

Для закрытого репозитория заменить `--public` на `--private`. Имя репозитория
также можно изменить. Если GitHub CLI ещё не авторизован, сначала выполнить
`gh auth login`. Git LFS отправит бинарные ассеты при `push`.

Альтернатива: добавить эту папку в GitHub Desktop как существующий локальный
репозиторий и выбрать **Publish repository**.
