# Лоупольные ассеты Fruit Example

В Unreal импортированы **44 Static Mesh**:

| Папка Content Browser | Содержимое |
|---|---|
| `/Game/Root/Assets/Meshes/Fruits` | 17 моделей фруктов, включая половинки |
| `/Game/Root/Assets/Meshes/Vegetables` | 21 модель овощей и грибов, включая половинки и ломтики |
| `/Game/Root/Assets/Meshes/Items` | Сердце, бомба, часы, 3 сюрикена |
| `/Game/Root/Assets/Textures` | Две общие цветовые палитры Kenney |
| `/Game/Root/Assets/Materials` | Материалы всех моделей |

Фрукты: яблоко, авокадо, банан, вишни, кокос, виноград, лимон, апельсин,
груша, ананас, клубника, арбуз; для части фруктов есть половинки.

Овощи: свёкла, брокколи, капуста, морковь, цветная капуста, сельдерей,
кукуруза, баклажан, лук-порей, грибы, репчатый лук, сладкий и острый перец,
тыква, редис, помидор; есть половинки, ломтики и варианты.

У всех моделей настроены материалы и простая выпуклая коллизия; Nanite
выключен. Дополнительные предметы имеют размеры: бомба 30 см, сердце 24 см,
часы 28 см, сюрикены 20 см по наибольшей стороне. Часы центрированы и
повёрнуты циферблатом вертикально. Модели содержат 42–1344 треугольника.

Это набор визуальных ассетов. Взрыв бомбы, прибавление жизни и времени
пока не подключены к игровым Blueprint. Половинки отдельных продуктов
являются самостоятельными моделями; автоматическое разрезание не добавлено.

## Источники и лицензии

Все использованные модели опубликованы под **CC0**. Сохранены исходные
архивы, лицензии Kenney, снимок страницы сюрикенов и метаданные часов.

| Автор | Набор | Использование |
|---|---|---|
| Kenney | [Food Kit 2.0](https://kenney.nl/assets/food-kit) | Фрукты и овощи, текстура-палитра |
| Kenney | [Platformer Kit](https://kenney.nl/assets/platformer-kit) | Сердце, бомба, текстура-палитра |
| mehrasaur | [3D Shuriken Pack](https://opengameart.org/content/3d-shuriken-pack) | Три сюрикена |
| scaranto | [Timer](https://poly.pizza/m/wZOaCBBiJ9) | Часы |

Адаптация: у сердца красный материал; у бомбы чёрный корпус и коричнево-золотой
фитиль; у сюрикенов стальной материал. Материалы часов восстановлены из
цветов исходного GLB. Размеры бонусов приведены к масштабу игрового примера.

Список импортированных ассетов с размерами и числом треугольников:
`asset-catalog.json`. Полные исходные наборы содержат и другие модели,
которые не импортированы в Content.

## Повторение импорта

Скрипты находятся в `Tools/AssetImport` и выполняются в открытом Unreal
Editor через `Tools/UnrealMCP/run_script.py`. `import_models.py` импортирует
до 8 отсутствующих моделей за запуск. `import_items.py` добавляет сюрикены
и первоначальную версию часов. Финальная подготовка предметов выполняется
`prepare_clock.py` на обычном Python и `polish_items.py` внутри редактора.
`verify_assets.py` проверяет результат. `polish_items.py` заменяет только
импортированные предметы, если на них ещё нет ссылок из других ассетов.
